# 문제 검증: adsp (데이터분석 준전문가 ADsP)

- 날짜: 2026-10-12 (특별 추가 — 새벽·오후 루틴과 별개, 사용자 요청)
- 방법: 정답·해설·choicesByLevel 을 뺀 파일(문제·선지만)을 별도 에이전트 3개가 나눠 처음부터 다시 풀었다 (40 / 40 / 34). R 출력 문제와 계산 문제는 python(scipy·statsmodels)으로 수치를 다시 계산했다. 별도 해설·수치 검토 에이전트가 정답·해설·오답 이유·R 동작·선지 줄이기(levelLock)를 검토했다. 수정한 문제는 별도 에이전트가 다시 풀었다.

- 다시 풀기: 114문제 모두 작성한 정답과 일치.
- 수정 후 통과 7: a-060("옳지 않은 것" 정답 선지가 글자 그대로는 참으로 읽힐 수 있어 '중앙값은 평균과 같은 6.2'로 교체), a-033·a-073(오답 선지를 실제로 나올 수 있는 값·용어로 교체), a-071·a-097·a-112(해설 수치·범위 표현 정정), a-015(문제 문장 다듬기). 7문제 모두 별도 에이전트가 다시 풀어 일치.
- 시험 구성: 데이터자격검정(dataq.or.kr) ADsP 자격소개 페이지를 직접 확인 — 필기 객관식 50문항(각 2점), 90분, 1과목 데이터 이해 10·2과목 데이터분석 기획 10·3과목 데이터분석 30문항, 총점 60점 이상·과목별 40% 미만 과락, 응시자격 제한 없음. 4지선다는 공식 페이지에 표기가 없어 수험 자료로 확인했다. 단원별 출제 비중은 공식 발표가 없어 세부항목 기준 추정.

## 개념 정리
- 8단원 모두 PASS. 검증 의견에 따라 출제 빈도 단정("매번") 완화, DIKW 예시, R 배열 차원, ARIMA·회귀 가정 표현, 우선순위 사분면 정의를 다듬었다.
