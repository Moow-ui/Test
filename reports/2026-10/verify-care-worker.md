# 문제 검증: care-worker (요양보호사)

- 날짜: 2026-10-21 (매일 루틴, 새벽)
- 방법: 정답·해설·핵심 개념·오답 순서를 뺀 파일만 받은 별도 에이전트가 153문항을 모두 다시 풀었다. 그림 문제는 `npm run images:render -- care-worker` 로 만든 PNG 를 보고 풀었다.
  법령 문항은 law.go.kr DRF API 로 받은 현행 노인장기요양보험법(2026-05-26 시행)·시행령(2026-05-12 시행, 제7조 등급 점수·제8조 유효기간)·노인복지법(2026-10-02 시행, 제39조의6·제39조의9)과 대조했다.
- 시험 구성: 국시원 시험시간표·배점(kuksiwon.or.kr/ss/subcnt/c_8015/7), 합격기준(c_8015/5), 노인복지법 시행규칙 제29조의2~8 — 필기(요양보호론) 35 + 실기 45 = 80문항, 90분, 객관식 5지선다, 필기·실기 각 만점의 60% 이상. 2026년 시험은 2024년 표준교재, 2027년 1월 시험부터 2026년 표준교재(국시원 2026-08-26 공지).

- 다시 풀기 153/153 일치. Q105(휠체어 놓을 자리, 그림): 그림의 "마비된 쪽" 표기가 대상자 기준 좌우와 반대여서 문제 글의 "왼쪽에 마비가 있는"을 "한쪽에 마비가 있는"으로 고친 뒤 별도 에이전트가 처음부터 다시 풀어 통과(①②③④ PASS).
- 심폐소생술 수치(분당 100~120회, 약 5cm)는 2020 한국 심폐소생술 가이드라인 기준. 2025 개정판(2026-01-29 발표)은 순서·방법을 유지했다는 발표로 확인 (kdca.go.kr 실행 환경에서 403).
- 작성 때 뺀 것(공식 근거 불확실): 목욕물 온도, 경관영양 높이·각도, 휠체어 각도, 교육 시간, 응시료, 본인부담률, 벌칙 금액, 2026 교재 변경 내용, 식후 시간 표현.

## 개념 정리

- 12단원 모두 1차 검증 PASS (검증 기록 `reports/2026-10/concepts-verify/verify-care-worker.json`).
- 검증 의견에 따라 summary 의 "6개월 이상"(카드에 없는 수치) 삭제, "비중이 가장 큰 단원"(공식 비중 없음) 표현 완화 2곳, 유효기간 카드 출처를 "노인장기요양보험법·시행령"으로 고침. 고친 4곳은 별도 에이전트가 다시 확인.
