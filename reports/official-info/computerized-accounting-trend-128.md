# 전산회계 1급·2급 출제 경향 메모 (제128회, 2026-10-03 시행)

- 근거: 회장이 시행기관 사이트(license.kacta.or.kr)에서 받은 제128회 A형 문제지. 문제지는 저작권 자료라 저장소에 넣지 않았다.
- **이 메모는 주제와 형식만 운영진이 요약한 것이다.** 문제 문장·숫자를 옮기지 않았고, 예상문제를 쓸 때도 기출 문장·숫자를 그대로 쓰거나 숫자만 바꿔 쓰지 않는다.
- 공통: 이론 15문항 × 2점, 4지선다, 제한시간 60분(이론+실무). 첫머리 전제 "따로 말이 없으면 일반기업회계기준 적용". 실무 문제는 이론 뒤에 이어진다(이 사이트는 이론만 다룬다).

## 전산회계 1급 — 이론 15문항

| 번호 | 영역 | 주제 | 형식 |
|---|---|---|---|
| 1 | 회계원리 | 유동자산 구분 (당좌차월처럼 헷갈리는 계정 섞기) | 아닌 것 고르기 |
| 2 | 회계원리 | 재무제표 작성·표시의 일반원칙 (계속기업, 경영진 책임, 통합 표시) | 틀린 것 고르기 |
| 3 | 회계원리 | 자본잉여금 항목 (자본조정·기타포괄손익과 구분) | 모두 고른 것 (가~라) |
| 4 | 회계원리 | 거래의 결합관계 (미지급 비용을 현금으로 지급) | 빈칸 짝 고르기 |
| 5 | 회계원리 | 기말 재고자산 포함 여부 (적송품, 미착품 인도조건, 반품조건부, 시용품) | 계산 (금액 고르기) |
| 6 | 회계원리 | 부채 계정 분류 (미지급금·선수금·단기/장기차입금·예수금) | 올바른 것 고르기 |
| 7 | 회계원리 | 대손충당금 보충법 + 매출채권 T계정 | 계산 |
| 8 | 회계원리 | 연구단계·개발단계 지출 구분 (무형자산 인식) | 계산 |
| 9 | 원가회계 | 종합원가계산 특징 (개별원가와 비교, 선입선출법·평균법, 완성품환산량) | 옳은 것 고르기 |
| 10 | 원가회계 | 원가행태 (고정원가·변동원가) | 분류가 다른 것 |
| 11 | 원가회계 | 기초원가(직접재료비+직접노무비) | 계산 |
| 12 | 원가회계 | 당기제품제조원가 (제조간접원가를 직접원가 비율로) | 계산 |
| 13 | 세무회계 | 우리나라 부가가치세의 특징 (간접세·물세·전단계세액공제법·비례세율) | 옳지 않은 것 |
| 14 | 세무회계 | 과세기간 (제1기·제2기, 간이과세자, 폐업자, 사업개시 전 등록) | 옳지 않은 것 |
| 15 | 세무회계 | 재화·용역의 공급시기 | 옳지 않은 것 |

- 배분: 회계원리 8 · 원가회계 4 · 세무회계(부가가치세) 3. 계산 문제 5개(5·7·8·11·12번), 나머지는 개념 판단.
- 부가가치세는 계산보다 제도(특징·과세기간·공급시기) 문장 판단이 나왔다.

## 전산회계 2급 — 이론 15문항 (전부 회계원리)

| 번호 | 주제 | 형식 |
|---|---|---|
| 1 | 회계의 순환과정 순서 (분개→전기→시산표→결산수정) | 순서 고르기 |
| 2 | 부채에 해당하는 계정 (채권·선급금과 섞기) | 몇 개인가 |
| 3 | 회계상 거래인지 (계약 체결은 거래 아님) | 아닌 것 |
| 4 | 자산 분류 (유동: 당좌·재고 / 비유동: 투자·유형·무형·기타) | 빈칸 짝 |
| 5 | 거래의 8요소 차변·대변 짝 | 잘못된 것 |
| 6 | 결합관계 (부채 감소 / 자산 감소)에 맞는 거래 | 옳은 것 |
| 7 | 통화대용증권 (자기앞수표 → 현금) | 대화형 빈칸 |
| 8 | 현금과부족 (원인 불명 부족) | 계정 고르기 |
| 9 | 매출채권·매입채무 묶기 (미수금·미지급금 빼기) | 계산 |
| 10 | 기말재고 과소평가 → 매출원가·매출총이익 영향 | 짝 고르기 |
| 11 | 유형자산 처분가액 (취득원가·감가상각누계액·처분손실) | 계산 |
| 12 | 외상매입금 T계정으로 현금 상환액 | 계산 |
| 13 | 회계등식 (자본등식·손익법) | 잘못된 것 |
| 14 | 판매비와관리비 정의 (매출원가와 구분) | 빈칸 짝 |
| 15 | 수익의 이연 (선수수익) vs 발생·비용 이연 | 계정 고르기 |

- 계산 문제 3개(9·11·12번). 계정과목 분류·거래 판단이 대부분이다. "몇 개인가"·순서·짝 문제가 많아 이런 형식은 `levelLock` 대상이다.
