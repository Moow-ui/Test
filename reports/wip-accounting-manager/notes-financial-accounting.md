# 재무회계(K-IFRS) — 문제에 쓴 사실 (financial-accounting)

## reporting-framework
- 근본적 질적특성: 목적적합성(예측가치·확인가치·중요성), 표현충실성(완전·중립·오류 없음).
- 보강적 질적특성: 비교가능성·검증가능성·적시성·이해가능성.
- 자산 = 과거사건의 결과로 기업이 통제하는 현재의 경제적자원(경제적효익 창출 잠재력을 지닌 권리; 유입 확률 요건 없음). 부채 = 과거사건 결과 경제적자원을 이전할 현재의무. 자본 = 잔여지분.
- 측정기준: 역사적원가 / 현행가치(공정가치, 사용가치·이행가치, 현행원가).
- 전체 재무제표: 재무상태표·포괄손익계산서·자본변동표·현금흐름표·주석. 이익잉여금처분계산서는 상법상 서류(주석 공시).
- 계속기업 평가: 적어도 보고기간말부터 12개월. 상계 원칙적 금지. 특별손익 표시 금지(본문·주석 모두).
- 유동/비유동: 보고기간말 현재 권리 기준. 보고기간 후 차환 약정은 유동 분류 유지. 이연법인세는 비유동.
- 재분류되는 OCI: FVOCI 채무상품 평가손익, 해외사업장 환산차이, 현금흐름위험회피 효과적 부분. 재분류 안 되는 OCI: 재평가잉여금, DB 재측정요소, FVOCI 지정 지분상품.
- 기능별 분류: 매출원가 분리 표시 + 감가상각비·종업원급여 등 성격별 정보 추가 공시.

## inventory
- 취득원가: 매입가격 + 매입운임·하역료·환급불가 세금. 판매원가·관리간접원가·비정상 낭비는 비용.
- 선적지인도조건 매입 미착품 = 구매자 재고; 도착지인도조건은 도착 전 판매자 재고.
- 위탁품: 수탁자가 팔기 전까지 위탁자 재고. 시송품: 고객이 구매 의사 표시 전까지 판매자 재고(원가로).
- 선입선출법: 기말재고 = 최근 매입분. 총평균법 단가 = 판매가능원가 ÷ 판매가능수량. 후입선출법 K-IFRS 불허.
- 순실현가능가치 = 예상 판매가격 - 완성원가 - 판매비용. 저가법 항목별 원칙(유사 항목 묶음 가능, 전체 총계 기준 불가).
- 평가손실 환입은 최초 장부금액(원가) 한도. 원재료는 제품이 원가 이상 판매 예상 시 감액 안 함(감액 시 현행대체원가가 NRV의 최선 추정일 수 있음).
- 매출원가 = 기초재고 + (총매입 + 매입운임 - 환출·에누리·할인) - 기말재고.

## tangible-intangible-assets
- 유형자산 원가: 구입가격 + 설치장소 준비·운송·설치·전문가 수수료 등 직접원가. 새 시설 개설·광고·일반간접원가는 비용.
- 건물 철거 목적 일괄구입: 전액 토지 원가 + 철거비 - 폐자재 처분수입 + 정지비·취득세.
- 교환(상업적 실질 有): 제공자산 공정가치(+현금 지급액)가 원가, 처분손익 인식. 실질 無: 제공자산 장부금액 기준, 손익 없음.
- 차입원가: 적격자산(상당 기간 필요)의 직접 관련 차입원가 자본화, 일시투자수익 차감, 완료 시 중단.
- 연수합계법: (원가 - 잔존가치) × 남은 연수/연수합계.
- 재평가: 증가 → OCI(과거 당기손실분은 먼저 당기이익 환입). 감소 → 재평가잉여금 먼저 차감, 초과분 당기손실.
- 손상: 회수가능액 = max(순공정가치, 사용가치), 장부금액 초과분 손상차손.
- 무형자산: 연구단계 지출 = 비용(구분 불가 시 연구단계로 봄), 개발단계는 요건 충족 시 자산. 비한정 내용연수: 상각 안 함, 매년 + 징후 시 손상검사.
- 투자부동산 공정가치모형: 감가상각 없음, 공정가치 변동 당기손익. 자가사용 부동산은 유형자산.

## financial-instruments
- 채무상품: 수취 목적 + SPPI → AC; 수취+매도 목적 + SPPI → FVOCI; 그 외 → FVPL.
- 지분상품: 원칙 FVPL. 단기매매 아니면 최초 인식 시 FVOCI 지정 가능(취소 불가), 처분 시 재분류(재순환) 없음, 손상 규정 없음.
- 유효이자율법: 이자수익(비용) = 기초 장부금액 × 유효이자율; 차이만큼 장부금액 조정.
  예) 액면 1,000,000, 표시 8%, 유효 10%, 3년 → 950,263 / 965,289 / 981,818 / 1,000,000; 이자 95,026·96,529·98,182.
- 사채 할인발행: 시장이자율 > 표시이자율, 이자비용 매년 증가, 총이자비용 = 표시이자 합계 + 할인액.
- 사채 할증발행 예) 액면 1,000,000, 표시 10%, 유효 8%, 3년 → 발행가 1,051,542, X1 이자비용 84,123, X1말 1,035,665.
- 기대신용손실: 1단계 12개월 ECL, 2단계(신용위험 유의적 증가) 전체기간 ECL, 3단계(신용손상) 전체기간 ECL + 이자수익은 순장부금액(상각후원가) × 유효이자율.
- 제거: 위험·보상 대부분 이전 → 제거, 대부분 보유(상환청구권 있는 어음할인 등) → 계속 인식 + 차입금.
- FVPL 거래원가는 즉시 당기비용(다른 분류는 공정가치에 가산).

## provisions-equity
- 충당부채: 현재의무(법적·의제) + 유출가능성 높음 + 신뢰성 있는 추정. 상대방 특정 불필요. 미래 영업손실은 인식 불가. 시간가치 중요 시 현재가치.
- 우발부채: 인식 안 함, 주석 공시(가능성 아주 낮으면 공시도 안 함). 우발자산: 유입 가능성 높으면 주석, 거의 확실하면 자산.
- 제품보증충당부채 = 추정 보증비용 - 실제 사용액.
- 확정기여: 기여금 납부로 의무 종료, 위험은 종업원. 확정급여: 위험 기업 부담, 예측단위적립방식, 재측정요소 OCI.
- DB 당기손익 = 근무원가 + 순확정급여부채 × 할인율(순이자).
- 자기주식 처분이익·손실은 자본 항목, 서로 상계(당기손익 아님).
- 주식배당·무상증자: 자본금 증가, 자본총계 불변, 액면 불변. 주식분할: 주식 수↑ 액면↓, 자본금 불변. 병합은 반대.
- 이익준비금(상법): 자본금 1/2까지 금전배당액의 1/10 이상(주식배당 제외).

## revenue
- 5단계: 계약 식별 → 수행의무 식별 → 거래가격 산정 → 배분 → 이행 시 수익 인식.
- 거래가격 배분: 개별 판매가격 비율(할인도 원칙적으로 비례 배분).
- 기간에 걸쳐 인식: 고객이 동시에 효익을 얻고 소비, 고객 통제 자산 창출, 대체용도 없음 + 집행가능 지급청구권. 그 외 한 시점.
- 진행률 = 누적 발생원가 ÷ 추정 총원가; 당기 수익·이익 = 누적 - 전기까지 인식액. 추정 변경은 전진 반영.
- 반품권: 반품 예상분은 환불부채, 반환제품회수권(원가 기준) 별도 자산.
- 보증: 확신유형 → 충당부채; 용역유형·별도 구매 가능 → 별도 수행의무. 법률 요구 보증은 확신유형 시사.
- 대리인(통제 없음: 재고위험·가격결정권 없음) → 수수료 순액 수익.
- 유의적 금융요소: 매출 = 현금판매가격, 차이는 유효이자율법 이자수익.

## other-topics
- 법인세비용 = 당기법인세 + 이연법인세 변동. 가산할 일시적차이 → 이연법인세부채, 차감할 → 이연법인세자산(실현가능성 높을 때). 할인 안 함, 비유동.
- 영구적 차이(접대비 한도초과 등)는 이연법인세 없음.
- 회계정책 변경(원가흐름 가정, 측정모형) → 소급. 회계추정 변경(내용연수·잔존가치·대손) → 전진. 전기오류 → 소급 재작성.
- 추정 변경 후 감가상각 = 변경 시점 장부금액 ÷ 남은 내용연수.
- 기말재고 오류는 다음 해 반대로 상쇄(자동조정오류), 2년 후 이익잉여금 영향 없음.
- 현금흐름표: 투자활동(유형·무형자산·타사 증권 취득·처분), 재무활동(차입·사채·주식발행·자기주식·배당 지급 선택), 영업활동.
- 간접법: 순이익 + 비현금비용 - 투자·재무 관련 이익 - 영업자산 증가 + 영업자산 감소 + 영업부채 증가 - 영업부채 감소.
- 지분법: 장부금액 + 순이익 × 지분율 - 수령 배당(배당수익 아님).
- 기본주당이익 = (순이익 - 우선주배당) ÷ 가중평균 유통보통주식수(기중 발행은 기간 비례).
