# 매일 자격증 추가 루틴 상태

루틴은 실행할 때마다 이 파일을 먼저 읽는다. 종료일은 없다. 중지·속도 변경은 이 파일로만 정한다.

| | |
|---|---|
| 상태 | 진행 |
| 새벽 루틴 | **내용 다듬기 기간: 내용 다듬기 1 + 새 자격증 1 (한국·미국 번갈아)** (매일 04:30). 기간이 끝나면 한국 1 + 미국 1 |
| 내용 다듬기 | 진행. 2026-11-04 시작, **목표 종료 2027-01-31 · 최종 기한 2027-02-28** (순서가 다 끝나거나 기한이 지나면 저절로 끝난다). 절차 [refine.md](refine.md), 순서 [reports/refine-progress.md](../reports/refine-progress.md). 멈추려면 "중지"로 고친다 |
| 오후 루틴 | **평소 꺼 둠** (2026-10-13부터). 회장이 주간 사용량에 여유가 있을 때 하루씩 예약 루틴 스위치를 켤 수 있다. 켜져서 실행되면 **미국 2개**를 추가한다 (한국 0 + 미국 2, 13:54. 2026-10-17 결정). 내용 다듬기 기간에는 **미국 1개 + 내용 다듬기 1개**. |
| 그림 보강 | 진행. 내용 다듬기 기간에는 다듬는 자격증 안에서 1건 (따로 하지 않는다). 기간이 끝나면 새벽 루틴 맨 끝에 하루 1건. 멈추려면 "중지"로 고친다 |
| 회장 요청 (전산회계) | **건너뜀 해제 (2026-11-06)**: 전산회계 1급(`computerized-accounting-1`)을 다시 고를 수 있다. 실패 원인은 루틴이 다른 주소(`license.kacpta.or.kr`)를 열려고 한 것. 공식 안내에 적힌 주소는 `license.kacta.or.kr`. 순서: 재경관리사를 게시한 뒤 **다음 한국 차례**에 `routine/wip-computerized-accounting-1` 초안에서 이어 한다 (초안은 검증 전이고 2026-11-04 이후 새 자격증 기준·현행 세법으로 다시 맞춘다). 시험 구성 근거는 `license.kacta.or.kr` 을 먼저 열고, 열리지 않으면 [회장 확인 자료](../reports/official-info/kacta-2026-11-06.md)를 공식 근거로 쓴다. 이론 문항 수(1·2급 모두 15문항 × 2점, 제한시간 60분은 이론·실무 합계)도 그 자료에 있다. 예상문제는 [제128회 출제 경향 메모](../reports/official-info/computerized-accounting-trend-128.md)에 맞춘다 (daily-routine.md 2-3). 그다음 한국 차례는 전산회계 2급. 둘 다 게시하면 이 행을 지운다 |
| 배포 파일 한도 | 20,000 (Cloudflare 무료 요금제. 유료 Workers Paid 로 바꾸면 100,000 으로 고친다) |

- **예약 루틴 지시문의 개수(새벽 "한국 1 + 미국 1", 오후 "미국 2")보다 이 표가 우선이다.** 내용 다듬기 기간에는 위 표대로 "다듬기 1 + 새 자격증 1"을 한다 ([daily-routine.md](daily-routine.md) 맨 위 안내).
- 시각은 한국시간이다.
- **오후 루틴 잠정 중지 중에도** 루틴 규칙(이 파일·`docs/daily-routine.md`·예약 루틴 지시문)을 고칠 때는 오후 루틴 쪽도 새벽 루틴과 같이 고쳐 둔다 (다시 켤 때 바로 쓸 수 있게).
- 상태가 "진행"이 아니면(예: "중지") 루틴은 아무것도 하지 않고 끝낸다.
- **배포 파일 한도 규칙 (자동)**: 루틴은 시작할 때 `npm run build` → `npm run check:deploy-size` 를 실행한다.
  "모드: 보강"이 나오면(배포 파일이 한도 - 1,000 개 이상) 그날은 **새 자격증을 추가하지 않고 기존 자격증의 문제를 보강한다**
  (`docs/daily-routine.md` 0-1). 사이트는 매일 계속 업데이트되고, 배포되지 못한 자격증이 쌓이지 않는다.
  한도를 올리면(요금제 변경·파일 수 줄이기) 다음 실행부터 저절로 "모드: 추가"로 돌아간다. 이 규칙은 개수 변경이 아니라 상태 규칙이므로 루틴이 스스로 따른다.
- 변경은 경영회의 결정으로만 한다. 바꿀 때는 위 표를 고치고 아래 변경 이력에 한 줄을 덧붙인다.

## 변경 이력

- 2026-10-09 회장 결정 — 10/29 이후에도 계속 진행
- 2026-10-09 회장 결정 — 배포 파일 한도 근처에서는 추가 대신 보강 모드로 매일 업데이트 유지
- 2026-10-12 회장 결정 — 새 자격증에 그림(그림 필요도에 따라)을 넣고, 기존 자격증은 새벽 루틴이 하루 1건씩 그림 보강
- 2026-10-13 회장 결정 — 사용량 나눠 쓰기: 하위 에이전트 동시 2개까지, 기출 옮겨 적기는 Sonnet, 필요한 파일만 넘기기, 고친 것만 다시 검증, 단계마다 중간 저장 (품질 기준 그대로, `docs/daily-routine.md` 0-2)
- 2026-10-13 회장 결정 — 무거운 자격증(기출 60문항 이상·법령 과목 3개 이상·250문항 이상)은 이틀에 나눠 진행하고, 진행 중에는 사이트 "기록" 페이지에 "이틀에 나누어 진행 중"으로 표시 (`docs/daily-routine.md` 1-2)
- 2026-10-13 회장 결정 — 주간 사용량 절약을 위해 오후 루틴 잠정 중지(무기한, 새벽 루틴만 진행). 오후 루틴 규칙은 계속 함께 고쳐 둔다
- 2026-10-17 회장 결정 — 기본은 새벽 루틴(한국 1 + 미국 1)만. 사용량에 여유가 있으면 회장이 가끔 하루씩 오후 루틴을 켠다 (규칙은 계속 함께 고쳐 둔다)
- 2026-10-17 회장 결정 — 미국 비중을 높이기 위해 오후 루틴은 한국 1 + 미국 1 대신 **미국 2개**를 추가한다 (새벽 루틴은 그대로 한국 1 + 미국 1)
- 2026-11-03 회장 결정 — 구글 노출 급감(10/26 무렵)에 대응해 **내용 다듬기** 시작: 새벽 루틴을 "새 자격증 1 + 기존 자격증 1개 다듬기"로 (11/4부터, 목표 2027-01-31 · 최종 2027-02-28, 끝나면 한국 1 + 미국 1 로 복귀). 그림 보강은 다듬기에 합침. 새 자격증도 처음부터 다듬은 기준으로. 매일 바뀌던 "검사 완료" 날짜를 없애고 "○○년 출제기준 반영"으로. 수험 정보 루틴은 그대로
- 2026-11-06 회장 결정 — 이용자 요청으로 재경관리사를 2026-11-07 새벽 루틴에서 우선 진행 (1회, 번갈아 규칙 예외)
- 2026-11-06 회장 결정 — 전산회계 1급 건너뜀 해제 (공식 주소 license.kacta.or.kr, 회장 확인 자료), 재경관리사 다음 한국 차례에 진행
- 2026-11-06 회장 결정 — 기출을 싣지 못하는 자격증도 최근 1회분을 읽고 출제 경향을 참고해 예상문제를 쓴다 (문제지는 저장소에 넣지 않고, 주제·형식 메모만 남긴다. daily-routine.md 2-3)
- 2026-11-06 회장 결정 — 보강 모드(0-1)에서 새 문제를 쓰기 전에 최근 기출 1회분으로 출제 경향을 맞춰 보고, 모자란 단원·형식부터 채운다 (기존 문제는 고치지 않는다)
